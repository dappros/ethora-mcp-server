# Security Policy

This plugin bundle contains no code of its own: it points Claude at the hosted
Ethora MCP server (`https://mcp.chat.ethora.com/mcp/oauth`) and ships two
skills (Markdown). Security reports for the server, the bundle or the skills
follow the policy of the repository that holds them:

- Preferred: GitHub private vulnerability reporting on
  https://github.com/dappros/ethora-mcp-server/security/advisories/new
- Email: `contact@dappros.com` with `SECURITY` in the subject line

We aim to acknowledge a report within 3 working days. Fixes land on the latest
published version of `@ethora/mcp-server` and the hosted server is updated
with every release. See the repository's `SECURITY.md` for the full policy.
